## [0.1.0] — 2026-03-31

### Added
- FastAPI backend with JWT authentication and SlowAPI rate limiting
- SQLAlchemy async ORM with Alembic database migrations
- GICS sector and sub-sector classification engine
- Altman Z-Score, Beneish M-Score, ICR, and FCF financial scoring models
- Redis caching layer with configurable TTL
- OHLCV price history tracking service
- DCF and comparable-company valuation engine
- Platt scaling and isotonic regression model calibration
- Ensemble risk model combining multiple scoring signals
- ESG and board-level governance risk assessment
- Point-in-time data reconstruction to prevent lookahead bias
- Analyst track record scoring with Brier metrics
- Event-driven backtesting engine
- VADER + transformer NLP sentiment analysis
- Chart.js frontend dashboard with live API integration
- Docker Compose deployment with Redis and PostgreSQL
- GitHub Actions CI/CD pipeline with coverage reporting
- Full pytest test suite across all services
